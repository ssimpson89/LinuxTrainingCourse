# LinuxTrainingCourse

Linux Internals training track: 14 mechanism-first modules covering a running
Linux system from permissions and PAM through the kernel, namespaces/cgroups,
eBPF tracing, SELinux, and early userspace.

- `content/` — the course modules in Markdown
- `docs/` — generated static website (build with `python3 build.py`, requires pandoc)

To read the course as a website, open `docs/index.html` in a browser, or enable
GitHub Pages on the `docs/` folder.
